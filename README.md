# erin-crawley.github.io

Personal website of Erin Crawley, postdoctoral researcher in physics at Harvard University.

Static HTML and CSS, served by GitHub Pages. No build step.

- `index.html` — the page
- `assets/css/style.css` — all styling; the palette and type live in the custom properties at the top
- `.nojekyll` — tells GitHub Pages to serve the files as-is rather than running Jekyll

The previous Academic Pages template site is preserved at the `pre-rebuild` tag.
